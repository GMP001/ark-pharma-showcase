# ARK Pharma - Pharmacy Management System

## Live Demo
- **Frontend**: https://incandescent-chimera-5ec01a.netlify.app
- **Backend API**: https://ark-pharma-api-vi.onrender.com

## Features
- Multi-tenant pharmacy management
- Inventory tracking
- Sales management (615,574.7 BDT total sales)
- 88 database tables
- Complete authentication system

## Tech Stack
- React + TypeScript (Frontend)
- Node.js + Express (Backend)
- PostgreSQL (Database)

## Quick Start
1. Clone the repo
2. Run `npm install` in both frontend and backend folders
3. Configure environment variables
4. Run `npm run dev`
